# AV PLAY PRO 本地运行说明

本项目包含在本地运行 AV PLAY PRO 所需的前端与 Tauri 配置。

AI Studio 项目地址: https://ai.studio/apps/f681e1b7-6773-4732-97a3-b837905fcb39

## 本地运行

**前置条件:** Node.js


1. 安装依赖:
   `npm install`
2. 在 [.env.local](.env.local) 中配置 `GEMINI_API_KEY`
3. 启动应用:
   `npm run dev`
